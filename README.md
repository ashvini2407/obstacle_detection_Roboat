# ESP32 Obstacle Avoidance Robot 

## Description
This project is an autonomous obstacle avoidance robot built using ESP32.

The robot uses an ultrasonic sensor to detect obstacles and automatically changes its direction to avoid them.

## Components Used
- ESP32
- Ultrasonic Sensor (HC-SR04)
- Servo Motor (SG90)
- L298N Motor Driver
- DC Motors
- Battery

## Working
The ultrasonic sensor detects obstacles in front of the robot. 
The servo motor scans different directions, and the robot automatically moves in a safe direction.
